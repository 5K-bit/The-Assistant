The Assistant is a local voice-and-HUD assistant for OBEOS: a skills library, an Obsidian-style vault as memory, and a localhost backend that routes commands to a local model.

**Pre-release.** First tagged release of a working project, for demonstration and controlled local use.

### What it does
- A backend on `127.0.0.1` with a live HUD, skill routing, vault read/write and vitals.
- Skill execution that writes only inside paths each skill declares, never overwrites or deletes, and runs in the background.
- Optional speech-to-text and text-to-speech through commands you configure.

### Verified
- 171 backend tests pass in CI with only pytest installed.

### Known limits
- Execution and voice are **off by default**; you must configure an engine and commands.
- The browser HUD tests (`tests/ui`) need Playwright and are not part of CI.
- Depends on a local model runtime you provide; answer quality is that model's.
